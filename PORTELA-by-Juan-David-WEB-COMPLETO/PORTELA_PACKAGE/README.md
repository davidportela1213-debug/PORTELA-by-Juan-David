# PORTELA by Juan David — Web V1

Proyecto web estático preparado para subir directamente a GitHub y posteriormente importar en Google AI Studio.

## Estructura
- `index.html` — entrada principal.
- `styles.css` — identidad visual, responsive y animaciones.
- `script.js` — microinteracciones.
- `assets/brand/` — logo oficial PORTELA.
- `assets/contact/` — QR de Instagram.
- `docs/` — documento maestro, datos de contacto y enlaces de proyectos.

## Proyectos incluidos
- La Sombra | Apropiación audiovisual de Nosferatu.
- Mi vida cotidiana — Entre planos y emociones.
- El grafiti en Colombia — Arte, Protesta y Memoria.
- Invitación digital interactiva — Baby Shower de Thomas.
- El Universo de Yangie — Experiencia digital personalizada.

## Portafolio fotográfico incluido
Esta versión ya contiene 5 pares reales Antes/Después entregados por Juan David, organizados en `assets/portfolio/fotografia/`. La correspondencia fue revisada visualmente y documentada en `docs/PORTAFOLIO_FOTOGRAFICO_MAPA.txt`.

## Publicación
Este proyecto no requiere backend. Puede publicarse en GitHub Pages, Vercel o un hosting estático equivalente.

## Para Google AI Studio
Importar el repositorio desde GitHub y usar el Prompt Maestro como instrucciones de diseño y evolución. No reemplazar recursos reales por stock ni inventar datos.
